# План ревью модуля discount.py

## Цели ревью
- Проверить, что базовая скидка 15% применяется только при cart_sum > 15000.
- Проверить, что цикл по promos не даёт уйти в минус.
- Проверить, что скидки по tier (0.97 и 0.93) не применяются
  одновременно.

## Измеримые критерии
- Все коэффициенты вынесены в переменные модуля:
  BASE_DISCOUNT = 0.85, SUMMER_BONUS = 500, VIP_DISCOUNT = 0.90,
  TIER1_DISCOUNT = 0.97, TIER2_DISCOUNT = 0.93, MAX_DISCOUNT_RATIO = 0.70.
  Проверка: `grep -n "0\.\|500" src/discount.py` не должен находить
  числа вне блока констант.
- Валидация на входе функции:
  - cart_sum > 0 (иначе Error);
  - tier = {0, 1, 2}.
- Покрытие тестами > 80% — на момент ревью тестов нет (0%),
  критерий вынесен как задача на следующий спринт.
